# Panda Leads Tools

Focused MCP server for public leads and enrichment from official data sources.

## When to use
- Find NPI providers, local businesses, hiring signals, or podcast guests
- Enrich websites/team pages, track topic trends, or look up trucking carriers
- Pull IRS nonprofits, building permits, new FL/TX/NY businesses, H-1B sponsors, or EU tenders

## When not to use
- Scholarly citations / literature → `panda-research-tools`
- Federal money / filings → `panda-public-funding-tools`
- Site, email, or agent safety → `panda-web-security-tools`

## Notes
- Requires `APIFY_TOKEN` (free Apify token). Each tool starts one Apify Actor run billed to that account.
- Prefer one or two inputs first; read the tool `summary` / `agentSummary` before widening.
